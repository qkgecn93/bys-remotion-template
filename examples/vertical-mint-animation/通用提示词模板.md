# 纯动画竖屏视频 · 通用制作提示词

> 用法：每期复制本模板，填好【本期信息】和【本期特殊要求】两处，连同素材发给 AI 助手即可开工。

## 一、任务与格式

做一期纯动画知识短视频（无真人出镜），竖屏 9:16、1080×1920、30fps，投抖音。
风格：清透水感·薄荷绿（亮色清新、白卡薄荷边框、深墨绿文字），有动效、不是 PPT。
一切风格以 `_starter/` 工程和其中的 `风格规范.md` 为准，保持各期统一。

## 二、【本期信息】（每期填写）

- 本期主题：（一句话）
- 逐字稿：`public/script.txt`（纯文本，必备）
- TTS 配音：`public/audio.mp3`（已生成就给；还没生成就写"后配"，先用估算时间轴做）
- 真实 SRT：`public/video.srt`（有就给，时间轴一律以它为准；没有就空着）
- 本期素材：`public/clips/` 下的图/视频清单（没有就空着，见"AI 授权区"）
- 本期 BGM：`public/bgm.mp3`（轻快风，自选；没选好可以先不加）
- 风格基准：`_starter/` + `风格规范.md`（保持各期统一）

## 三、呈现形式（纯动画版式套路）

- 每段一个场景（`Main.tsx` 里一个 `<Seg a b>`），一帧只讲一件事。
- 段落节奏跟稿子走：钩子（全屏大字）→ 分段标题（StepTitle）→ 要点（CardsRow，居中纵排，最多 3 张）→ 对比/素材（BeforeAfter / MediaPanel）→ 结尾三连（EndScene）。
- 优先拼 `src/scenes/blocks.tsx` 的通用块（用法见 `src/scenes/_cookbook.md`），不够再写自定义场景（一段一个文件，放 `scenes/`）。
- 元素出现必须用 `cueAt` 跟配音：说到那句，元素才出现，不许整段一次全亮。

## 四、字幕与时间轴

- 有真实 SRT：以它为准，跑 `python tools/srt_to_captions.py public/video.srt tools/keywords.json`。
- 没有 SRT（常态）：跑 `python tools/estimate_captions.py public/script.txt tools/keywords.json` 按稿估轴，并在交付说明里提醒我拿到 TTS 真实 SRT 后重跑对轴。
- 跑完脚本把 `src/theme.ts` 的 `DUR` 改成脚本提示的时长。
- 底部字幕：句尾无标点；底部安全区 320px；每句最多一个【】关键词高亮（关键词写进 `tools/keywords.json`）。
- 钩子段（约前 4 秒）隐藏底部字幕，用全屏大字（`<Captions minStart={4} />`，按实际钩子长度调）。

## 五、开头钩子

- 前 3 秒定生死：用全屏大字 `BigStatement` 抛一个疑问/反常识/数字冲击（例：「为什么你越努力，越【焦虑】？」）。
- 钩子里必须有一个薄荷高亮关键词；副标题一行点明本期给什么（例：「3 个习惯 · 让效率翻倍」）。
- 钩子段不出底部字幕、不放要点卡，画面只有大字 + 装饰圆环。

## 六、画面与文案红线

- 数据和事实不杜撰；产品/人名/书名用真实名称；拿不准的先问我或联网核实（见授权区）。
- 亮色底座文字规矩：文字深墨绿；`textDim` 只在白卡内用；压素材图/视频的文字必须 `SHADOW_ON_MEDIA` 强阴影 + `onMedia` 暗场；白底高亮用加深薄荷字 + 淡底衬，不用浅色发光。
- 所有颜色只从 `src/theme.ts` 取，禁止场景里写死色值。
- 动效统一 `ci` 缓动，禁止 CSS transition；图片按比例选 cover/contain；素材间隙不留空场。

## 七、声音

- TTS 配音 `audio.mp3` 为主轨。生成 TTS 后建议做一遍响度归一化（需 ffmpeg）：
  ```bash
  # 第一遍测量
  ffmpeg -i audio_raw.mp3 -af loudnorm=I=-15:TP=-1.5:LRA=11:print_format=json -f null -
  # 第二遍按测量值写入（把 measured_* 换成第一遍输出的值）
  ffmpeg -i audio_raw.mp3 -af loudnorm=I=-15:TP=-1.5:LRA=11:measured_I=..:measured_TP=..:measured_LRA=..:measured_thresh=..:offset=.. -ar 44100 audio.mp3
  ```
- BGM：轻快风，音量 0.10-0.15（`<Audio volume={0.12} />`），不许盖过配音；本期没选曲就保持注释。
- 音效：少而精，默认不加；要加先在【本期特殊要求】里写。

## 八、AI 授权区

- 资料不够时：**可以**直接联网搜索补充，不用每次问我；引用的数据在交付说明里附来源。
- 缺素材图时：**可以**自己找或生成占位素材，但必须在交付说明里标注哪些是占位、来源是什么，方便我替换。
- 红线：数据、事实、引语一律不杜撰；查不到就明说查不到。

## 九、交付物

- 每期交付：**可编辑 Remotion 工程**（我自己在 Studio 预览和渲染），不需要渲成片 MP4。
- 工程红线：不打包 node_modules、不写死本机/浏览器路径、字幕集中在 `captions.ts`（脚本生成）、每段一个场景文件、只在 `_starter` 副本上改（`_starter/` 本体保持干净）。

## 十、工作流程

1. 读完本模板和素材后，先用 3-5 句话复述你对本期的理解（主题、段落划分、钩子方案），**等我确认再动工**。
2. 复制 `_starter/` 为本期新工程文件夹（如 `EP01-主题名/`）。
3. 素材入 `public/`，跑字幕脚本（按第四节选对脚本），更新 `DUR`。
4. 按第三节套路在 `Main.tsx` 写段落、拼场景块。
5. 搭好后先给我 2-3 张关键帧截图（或让我在 Studio 里看指定帧号）确认风格，再继续填完所有段落。
6. 交付：工程文件夹 + 一段交付说明（本期段落表、占位素材清单、还差什么、拿到真实 SRT 后要做什么）。
