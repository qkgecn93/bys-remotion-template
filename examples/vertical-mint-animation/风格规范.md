# 风格规范 · _starter（清透水感·薄荷绿）

跨期不变的规矩都钉在这里。做每期视频前读一遍；改风格必须先改这里，再改 theme.ts。

## 0. 风格档案（V2-rev 定稿，与 theme.ts 一一对应）

```
主背景   #f6fbf9（薄荷白，Remotion 里为纯色；场景内可加细线圆环装饰）
面板     #ffffff / 边框 2px rgba(23,176,146,0.38) / 圆角 卡 20 · 字幕条 16
主色     #17b092 (RGB 23,176,146) / 高亮文字 #0f9c81 + 底衬 rgba(23,176,146,0.14)
辅助浅色 #a7e8db（只做装饰，不做文字色）
文字     主 #123a33（深墨绿）/ 次级 #3f6b62 / 弱字(仅白卡内) #7d968f
投影     卡 0 20px 60px rgba(23,176,146,0.12)
阴影     浅底文字轻阴影 0 2px 10px rgba(18,58,51,0.15)；压素材用 SHADOW_ON_MEDIA 强阴影
字号     大字 92/900 · 段落标题 84/900 · 卡标题 38/800 · 字幕 56/700 · kicker 24/700 ls6
画幅     1080×1920 竖屏 @30fps（抖音）
```

## 1. 配色与换色规矩

- 全项目颜色只允许来自 `src/theme.ts`，换色只改 theme.ts 一处，禁止在场景里写死色值。
- 高亮/描边/投影一律走 `rgba(${accentRGB},…)`，保证换主色时联动。
- 亮色底座三条铁律：
  1. 文字永远是深墨绿系，不用白字（除非压在素材上并带强阴影）。
  2. `textDim` 弱字只允许出现在白色卡片内部。
  3. 白底上的关键词高亮 = 加深薄荷字 `accentDeep` + 淡薄荷底衬，**不用浅色发光**。

## 2. 文字清晰度规矩

- 浅色背景上的大字：默认轻阴影 `SHADOW`。
- 压在素材图/素材视频上的文字：必须 `SHADOW_ON_MEDIA` 强阴影，并开 `onMedia`（暗场 Scrim 的透明度绑内容出现进度——有字才压暗）。
- 禁止把 `textDim`、`accentSoft` 当正文字色压在任何画面上。

## 3. 纯动画版式与节奏

- 节奏跟稿子走：每段一个 `<Seg a b>`，元素用 `cueAt` 跟配音出现（说到哪句，元素才出现）。
- 要点卡居中纵排（宽 760），一屏最多 3 张；更多要点拆成两段。
- 留白是本风格的一部分：单帧只讲一件事，装饰圆环不超过 3 个、透明度不超过 0.2。
- 素材间隙不留空场，用 `BigStatement`/`StepTitle` 补动画。

## 4. 字幕规矩

- 底部字幕条：白底 92% 透明度 + 薄荷边框，深墨绿文字 56/700，底部安全区 320px（避开抖音 UI）。
- 句尾不加标点（脚本自动去除）。
- 关键词【】高亮，每句最多 1 个关键词，keywords.json 维护。
- 钩子段（开头 3-5 秒）隐藏底部字幕，用全屏大字代替（`<Captions minStart={钩子结束秒} />`）。
- 时间轴优先级：真实 SRT（srt_to_captions.py）> 逐字稿估算（estimate_captions.py）。估算轴只是过渡，拿到 TTS 真实 SRT 必须重跑对轴。

## 5. 动效规矩

- 全项目统一 `ci` 缓动（快进慢停），回弹只用 `OVERSHOOT`，禁止 CSS transition/animation。
- 入场动画统一走 `useRise`/`usePop`，时长 0.5-0.7 秒；卡片依次出现间隔 0.35 秒。
- 元素出现必须跟配音（`cueAt`），不许整段内容一次全亮出来。

## 6. 声音规矩

- TTS 配音放 `public/audio.mp3`，全程主轨。
- 建议对 TTS 成品做一遍响度归一化（ffmpeg loudnorm，I=-15 / TP=-1.5 / LRA=11，命令见《通用提示词模板.md》）。
- BGM 轻快风，每期自选曲子放 `public/bgm.mp3`，Remotion 里音量 0.10-0.15，不许盖过配音。
- 音效原则：少而精，关键动效点缀即可，默认可以不加。

## 7. 个性化项

- 落款：结尾用底部字幕说「记得点个关注，我们下期见」，EndScene 里不重复文字落款。
- 结尾三连引导页：保留（EndScene：点赞/收藏/关注/转发）。
- 不预留 logo/头像位。
