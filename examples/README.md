# 生成样例

这里是本 Skill 真实跑出来的产物，用来回答一个问题：**跑完之后我到底能拿到什么？**

两份样例来自两个不同的用户画像，说明同一个 Skill 会长出完全不同的两套东西。

## vertical-mint-animation · 抖音竖屏 · 纯动画 · 薄荷绿

用户画像：做抖音的，纯动画不出镜，TTS 配音，要底部字幕但没有 SRT，喜欢亮色清新。

| 文件 | 说明 |
|---|---|
| `风格效果图_选定版.html` | 1080×1920 精确尺寸，含钩子大字帧 + 要点卡帧。这是用户在 3 版里挑中并提过一轮修改（"高亮太浅、边框太淡"）之后的定稿版 |
| `通用提示词模板.md` | 用户的专属开工单，11 个章节全部落到具体值，含 AI 授权区和交付红线 |
| `风格规范.md` | 跨期不变的规矩：配色、文字清晰度、版式、字幕、动效 |
| `theme.ts.sample` | 生成的工程控制台，风格档案逐值落地 |

浏览器打开那个 HTML 就能看到效果图长什么样。

## landscape-dark-tech · B站横屏 · 真人口播 · 暗色科技

用户画像：知识区 UP 主，横屏，有录好的口播，说"喜欢暗色科技感那种"。

三版效果图对应同一个风格方向的三种倾向，用来演示"挑选"这一步是怎么发生的：

| 文件 | 倾向 |
|---|---|
| `风格效果图_V1冷蓝霓虹.html` | 更冷更极客 |
| `风格效果图_V2暖橙发光.html` | 更暖更亲和，圆角更大 |
| `风格效果图_V3紫青渐变.html` | 赛博感更强 |

每版都是 1920×1080 精确尺寸，含三张关键帧：钩子大字帧、要点卡帧、**角落人脸帧**（口播形态的招牌画面，用渐变块占位而非真人图）。

## 说明

- 这些是模拟用户跑出来的**真实产物**，不是手写的示意稿。
- 效果图里的人脸位置一律是占位色块，Skill 不会在效果图阶段要你的素材。
- 你自己跑出来的会和这两份都不一样——那才是重点。
