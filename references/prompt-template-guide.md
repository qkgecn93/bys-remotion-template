# 通用提示词模板生成指南（第 4 步之二）

《通用提示词模板.md》是用户以后每期视频的"开工单"：复制一份 → 填【本期信息】和【本期特殊要求】→ 连素材发给 AI 助手。生成时按用户形态**只出一份**，把访谈里定下的一切写死进去，让以后任何一个新对话拿到它就能稳定复现风格。

## 必含章节（按序）

1. **任务与格式**：一句话定调（画幅、分辨率、fps、风格一句话、形态）。
2. **本期信息（每期填写）**：素材清单（按形态）+ "风格基准：`_starter/` + `风格规范.md`（保持各期统一）"。
3. **呈现形式**：该形态的版式套路（口播：前景卡片 vs 角落动画两种形式怎么选；纯动画：段落节奏；录屏：包装规则）。
4. **字幕与时间轴**（若有）：SRT 为准、高亮规矩、钩子段处理、跟读音出现。
5. **开头钩子**：前几秒决定留存，写清该用户偏好的钩子打法。
6. **画面与文案红线**：不杜撰、真实名称、文字清晰度、版式规矩（从风格规范浓缩）。
7. **声音**（按访谈）：口播 loudnorm 两遍归一化完整命令 / BGM 音量规范 / 音效原则。
8. **AI 授权区**（Q6 的答案）：能否联网补料、能否自找素材、必须先问的事项。
9. **交付物**：工程红线（可编辑工程/成片、不打包 node_modules、不写死路径、captions.ts 集中、每段一场景）。
10. **工作流程**：从复制 _starter 到交付的编号步骤，含"先沟通再开工""搭好后先给关键帧确认风格"。
11. **【本期特殊要求】**：留空表格/清单 + 2-3 行填写示例。

## 写法要求

- 用第一人称对 AI 说话的口吻（"做一个……""以 video.srt 为准"），因为它未来会被直接粘贴给 AI。
- 所有访谈答案落地为**具体值**（分辨率、LUFS 值、安全区 px、圆框直径），不留"看情况"。
- 顶部加用法注释：`> 用法：每期复制本模板，填好两处【】发给 AI。`
- 页脚轻署名一行：`> 由 不一书Remotion模板生成器 (bys-remotion-template) 生成`
- 若 remotion-best-practices 未安装，在模板备注里写明规则获取地址（GitHub remotion-dev/remotion/packages/skills）。

## 口播形态骨架示例（节选，供参考语感）

```markdown
# 口播视频 · 通用制作提示词

> 用法：每期复制本模板，填好【本期信息】和【本期特殊要求】发给 AI。

## 一、任务与格式
做一期知识口播风格视频，竖屏 9:16、1080×1920、30fps，暖橙暗色科技风，有动效、不是 PPT。

## 二、本期信息（每期填写）
- 口播视频：`video.mp4`（音轨即口播，全程使用）
- 真实字幕：`video.srt`（时间一律以它为准）
- 风格基准：`_starter/` + `风格规范.md`
...
```
