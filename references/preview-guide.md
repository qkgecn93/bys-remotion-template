# 风格效果图指南（第 2 步）

目的：让用户**看着图做决定**，而不是想象。HTML 模拟图几秒就能出，先用它定风格；最终一致性由第 5 步的真实 Remotion 渲染兜底。

## 做几版、做哪些帧

- 按用户选的风格方向出 **2-3 版**，每版有明显不同的倾向（例如同是暗色科技：V1 冷蓝霓虹 / V2 暖橙发光 / V3 紫青渐变），让"挑"有意义。
- 每版至少两张关键帧：
  1. **钩子大字帧**：全屏中心大字 + 关键词高亮（口播形态叠一个人脸占位：用纯色渐变块 + "口播画面"字样标注，不要用真人图片）。
  2. **要点卡帧**：2-3 张信息卡（口播形态放两侧，纯动画放中央），含英文小标 + 中文标题。
- 口播形态加第三张：**角落人脸帧**（右下角圆框占位 + 主画面大字/素材面板），这是该形态的招牌画面。

## 制作规范

- 尺寸 = 用户画幅的精确像素（1920×1080 或 1080×1920），单文件 HTML，`<div>` 固定像素布局，禁止响应式——这是视频帧不是网页。
- 字体：中文用系统字体栈（思源黑体/苹方/微软雅黑），字号按最终视频的真实字号做（横屏大字 ≈110px、卡片标题 ≈38px、字幕 ≈44px），让用户对"字有多大"有真实感受。
- 每张帧的设计参数（背景色、主色 RGB、发光强度、圆角、边框透明度、字号）写成 HTML 顶部注释块，选定后直接搬进 theme.ts。
- 交付方式：每版一个 HTML 文件（内嵌所有帧，纵向排开，帧外加标签"V1-钩子帧"等），保存到用户可见文件夹后用文件展示工具发给用户。若环境有浏览器截图能力，可另附 PNG。

## 对话方式

发图时给一句每版的定位（"V1 更冷更极客，V2 更暖更亲和"），然后问：
> 直接选一版，或告诉我"V1 的底色 + V2 的橙色"这种混搭，或提任何修改（颜色/圆角/字号/发光强度）都行。

用户提修改 → 只改被点名的参数重新出一版 → 再确认。**用户没说"就这版"之前不进第 3 步。**

## 选定后记录

把最终参数整理为一个"风格档案"块（后续写 theme.ts、风格规范.md 用）：

```
主背景 #0b0f14 / 面板 rgba(255,255,255,0.05)
主色 #ff8c3f (RGB 255,140,63) / 辅助 #ffc59f
文字 #f5f7fa / 次级 #ffe3cf / 弱字(仅卡内) #8a93a3
圆角 卡20 面板18 / 发光 0 0 32px rgba(主色,0.18)
大字 110/900 / 卡标题 38/800 / 字幕 44/700
```
